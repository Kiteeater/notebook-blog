# Blog Series 功能实现方案

## 目标
给 blog 加正交于 category 的「系列」维度：同一 series key 的多篇文章按 date 升序组成有序集合。数据单一来源 = 文章 front-matter，零额外 manifest。

## 数据模型

### `src/lib/types.ts` — `PostMeta` 加两个可选字段
```ts
export type PostMeta = {
  // ...existing fields
  series?: string;       // 系列 key（slug-safe，如 "kimi-k3"）
  seriesTitle?: string;  // 系列展示名（如 "Kimi K3 架构全解"）
};
```
顺带在 `Series` 类型上挂 `description`（取首篇 description）。

### front-matter 用法
```yaml
series: kimi-k3
seriesTitle: "Kimi K3 架构全解"
```
顺序 = 系列内文章按 date 升序；part 号 = 升序中的序号（1-based）。

## lib 层

### `src/lib/posts.ts`
`getAllPosts()` 和 `getPost()` 在 `matter` 解析后多取两个字段：
```ts
series: data.series as string | undefined,
seriesTitle: data.seriesTitle as string | undefined,
```

### `src/lib/series.ts`（新增，纯函数）
```ts
export type Series = {
  key: string;
  title: string;        // 系列展示名（系列内任一篇的 seriesTitle，以最早一篇为准）
  description: string;  // 取首篇（按 date 升序）的 description
  posts: PostMeta[];    // 升序
};

export type SeriesContext = {
  series: Series;
  index: number;        // 0-based
  total: number;
  prevInSeries: PostMeta | null;
  nextInSeries: PostMeta | null;
};

export function getAllSeries(): Series[];                    // 按 series 分组、组内升序；系列间按首篇 date 倒序
export function getSeriesPosts(seriesKey: string): PostMeta[];// 升序
export function getSeriesContext(slug: string): SeriesContext | null;
```

## 路由 / UI

### 1. 文章页 `src/app/writing/[slug]/page.tsx`
- header eyebrow 下方加系列条（仅 `getSeriesContext(slug)` 非空时）：
  `SERIES · Kimi K3 架构全解 · 第 2 / 4 篇`，整条链接到 `/series/<key>`，用现有 `.eyebrow` + `data-enter`
- 文章底部「上一篇 / 下一篇」下方再加一组「系列内上一篇 / 下一篇」，样式完全复用现有 `border-t` + `pt-6` + `.eyebrow` + `NavLink`，不新增 class

### 2. 索引卡片 `src/components/writing/PostCard.tsx`
- 信息行（`categoryLabel · date · readingTime`）最前面加一个文字胶囊：`S · {seriesTitle 简称}`，描边用 `var(--hairline)`，字号 `.eyebrow`。无 series 不渲染。
- 不碰 WebGL 层（CardSceneCanvas / CardTextLayer），角标只在 DOM 卡片信息行

### 3. 系列落地页 `src/app/series/[slug]/page.tsx`（新增）
- `generateStaticParams` 从 `getAllSeries()` 出 slug
- `generateMetadata` 出 title/description
- 复用文章壳层排版（`max-w-[760px]` / `pt-28` / `.eyebrow` / `font-display` / `TopVeil` / `ScrollDrift`）
- header：eyebrow `SERIES`、H1 系列名、首篇 description、`{N} 篇`
- 目录列表：每行 `Part N · date · 标题`，链接 `/writing/<slug>`，hairline 分隔，`NavLink` 走 transition

### 4. 不动
- `GlobalHeader.tsx` 顶部 NAV 保持 Index/Writing/About 三项
- `src/app/api/posts/route.ts` 直接吃新字段，无需改
- `globals.css` 零改动，全部用现有 token / class
