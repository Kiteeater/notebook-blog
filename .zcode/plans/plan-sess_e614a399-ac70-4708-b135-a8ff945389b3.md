## 目标

在 Writing 页 header 内加搜索能力，复用全站已有的液体美学体系（`liquid-rise-in` crossfade、`.nav-swap` masked slide、`useLiquidPush` 推流、`.pill-filter` 描边胶囊），不新增动画、不新增 rAF 循环。

## 交互模型

分类行左侧加一个搜索 icon。点 icon → 分类行 crossfade 成搜索框（互斥视图，复用 `.segmented-pane` 的 `liquid-rise-in`）。
- 搜索框：圆角描边胶囊，聚焦时 placeholder 文字走 `.nav-swap` masked slide 被推走，右侧内联 ✕ 清空。
- 输入时实时过滤（debounce 120ms），结果走与分类相同的 `filtered` 渲染路径（DOM 网格 / WebGL 场景都自动适配）。
- ✕ 或 Esc → 清空 + 切回分类视图。切回即清空搜索词。
- 搜索态下分类 filter 保留但不展示；结果是 `分类 ∩ 搜索词`。

## 改动文件

### 1. `src/components/writing/WritingIndex.tsx`（核心）

**新增状态**：`view: "filters" | "search"`、`query: string`、`debounced: string`。

**搜索 icon 按钮**（新增小组件 `SearchToggle`）：
- 挂 `useLiquidPush`（非搜索态启用，搜索态禁用）。
- SVG 放大镜描边（strokeWidth 1.2，currentColor），复用 PostCard 箭头的笔触。
- 圆角描边容器，hover 实心深底（对齐菜单按钮 / pill-filter）。
- 点击切 `view`。

**搜索框**（新增小组件 `SearchField`）：
- 外层 `.pill-filter` 基底样式拉长（`min-w-[200px]`），但不用 `<button>`——是 `<input>` + 内层 `.nav-swap` placeholder。
- placeholder 双层（swap-a 显示「搜索文章…」，swap-b 显示聚焦态提示），聚焦触发 masked slide。
- 右侧 ✕ 按钮：仅 `query` 非空显示，hover 实心，点击清空 + 切回分类视图。
- 挂 `useLiquidPush(false)`（输入时不晃，避免打字漂移）。

**header 控件行**：
- 外层 div 加 `key={view}`，触发 `liquid-rise-in` 重挂载浮上（和 SegmentedControl 的内容切换同机制）。
- `view === "filters"` → 渲染原 `FilterPill` 列表。
- `view === "search"` → 渲染 `SearchField`。

**过滤逻辑**：
```
const searched = debounced.trim()
  ? posts.filter(matches)   // title/description/tags/categoryLabel 含 debounced（小写）
  : posts;
const filtered = filter === ALL ? searched : searched.filter(p => p.category === filter);
```
- debounce：`useEffect` + setTimeout 120ms 写 `debounced`，cleanup 清 timer。
- `filtered.length` 变化已驱动 WebGL 场景 resize（现有 effect）。

**Esc 监听**：搜索框 `onKeyDown` 处理 Esc → 清空 + `setView("filters")`。

**空状态**：复用现有「该分类下暂无文章」文案，改为「未找到匹配文章」。

### 2. `src/app/globals.css`

新增样式（追加到现有 segmented/pill 区块附近，不重写）：
- `.search-field`：基于 `.pill-filter`，去掉 count，拉长宽度，聚焦时描边加深（不用实心深底——输入框深底配浅字不好读，保持浅底深字）。
- `.search-field input`：透明背景、无边框、outline none、继承字色。
- `.search-clear`：右侧 ✕ 按钮，hover 实心。
- `.search-icon-btn`：icon 容器，hover 实心深底（对齐菜单按钮语义）。

## 不改的东西

- `SegmentedControl.tsx`：不碰，那个组件是给整块 content 切换用的，这里需要的是 header 内联切换，语义不同。
- WebGL 层（`CardSceneCanvas`/`CardTextLayer`/`cardScene.ts`）：接收 `filtered`，自动跟着走。
- `posts.ts` / API：纯前端过滤，不需要。
- `.nav-swap` / `liquid-rise-in` / `useLiquidPush`：直接复用，零改动。
