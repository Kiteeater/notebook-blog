## 假 3D：拖拽视差强化背景空间感

目标：让现有 2D 全屏 shader 产生"相机在空间里平移/扫摄"的错觉（unseen.co 式探索感），不引入真 3D / OrbitControls，不改 DOM 架构。

---

### 改动 1 — `src/lib/sceneState.ts`：加 4 个 pan 字段

在 `sceneState` 对象里（`mouseVY` 之后）新增：
```ts
// 拖拽平移相机（假 3D 视差）。pointer 写 target，render loop 缓动 current
panTX: 0,   // -1..1 目标
panTY: 0,
panX: 0,    // 缓动后当前值，喂 shader
panY: 0,
```
跟 `mouseTX/mouseX` 同构，零新约定。

---

### 改动 2 — `src/components/scene/SceneCanvas.tsx`：加拖拽监听 + render loop 缓动

**(a) 新增 pointerdown/move/up 监听**（在现有 `onPointer` 之后）：
- `pointerdown`：仅左键(0)、非 touch、非 reduced、非菜单打开时记录起点 + 设 `dragging=true`。不 `preventDefault`、不 `setPointerCapture`（避免抢 Lenis/卡片 `<a>` 事件）。
- `pointermove`：若 `dragging`，算当前位置相对起点的归一化位移；超过阈值(6px)才写 `sceneState.panTX/panTY`（clamp 到 ±1）。
- `pointerup`/`pointercancel`：`dragging=false`。**不归零 pan** —— 松手后视角留在拖到的地方，render loop 用现有缓动自然回落回 0（见下）。

**(b) render loop 缓动**（在 `sceneState.scroll` 缓动附近）：
```ts
// pan 缓动回落到 0：松手后相机自动回正（有惯性），拖拽时 target 由指针实时写
const panLerp = dragging ? 0.25 : 0.04; // 拖拽时跟手、松手后慢回落
sceneState.panX += (sceneState.panTX - sceneState.panX) * k * panLerp;
sceneState.panY += (sceneState.panTY - sceneState.panY) * k * panLerp;
// 松手时 target 缓慢回零（让 panX 自然归位）
if (!dragging) { sceneState.panTX *= 0.98; sceneState.panTY *= 0.98; }
```
`reduced` 时强制 panX/panY=0（沿用现有模式）。

**(c) 加 uniform**：`uPan: { value: new THREE.Vector2(0,0) }`，每帧写入 `sceneState.panX/panY`。

---

### 改动 3 — `src/components/scene/sceneShader.ts`：用 uPan 做深度视差

加 `uniform vec2 uPan;`。在 `hall()` 函数的碑板循环里（现有 `q.x += uMouse.x * 0.055 * par` 那行附近），按层深做**差异视差**：

```glsl
// 假 3D：pan 驱动相机平移，远景层位移小、近景层位移大
float panStrength = 0.18 * (1.0 - depth);   // depth 越小越近 → 位移越大
q.x += uPan.x * panStrength;
q.y += uPan.y * panStrength * 0.7;
```

地平线 + 地面反射也微响应 pan（在 `main()` 里 `floorY` 区域加 `floorY += uPan.y * 0.04`，制造"低头/抬头"错觉）。

顶光/日源位置微随 pan 偏移（`hall()` 里 `lp.x += uPan.x * 0.06`），强化空间纵深。

---

### 改动 4 — 菜单打开时禁用拖拽

`SceneCanvas` 目前不读 React 状态。最小侵入方案：在 `sceneState` 加一个 `menuOpen` 布尔（默认 false），由 `MenuOverlay`/`TransitionProvider` 在打开/关闭时写。`SceneCanvas` 的 pointerdown 守卫读它。

（探索确认：`MenuOverlay.tsx` 有 open/close 逻辑，加一行 `sceneState.menuOpen = next` 即可。）

---

### 不改的东西
- DOM 架构、卡片网格、Lenis、正文、Hero、无障碍 —— 全不碰。
- 现有 `mouseX` 鼠标视差保留（pan 是叠加，不替换）。
- touch 仍跳过（沿用 `pointerType === "touch"` 惯例）。
- reduced-motion 仍跳过（沿用 `sceneState.reduced` gate）。

---

### 验证
- `npx tsc --noEmit` 零报错。
- 手测：首页拖拽 → 背景碑板层明显错位平移、松手慢回正；文章页正文仍可选可滚；writing 页卡片点击仍能跳转（拖拽阈值保证 click 不被劫持）。
