用现成的平台多省事——Medium、知乎、公众号，注册个号就能写。为什么还要从零搭一个？

答案藏在「拥有」这个词里。

## 平台是租来的房子

在别人的平台上写作，本质上是租房。房东随时可以涨租、改规则、甚至把你赶出去。你写的东西、积累的读者、沉淀的链接，都不真正属于你。

> 内容是你的，但承载内容的容器不是。

更隐蔽的问题是**审美妥协**。每个平台都有自己的视觉语言，你的文字被迫穿上别人的衣服。一个认真写字的人，理应拥有自己文章的排版、字体、留白——这些不是装饰，是表达的一部分。

## 自己搭，是一次自我对话

从零搭博客的过程，逼着你回答一连串问题：

- 我希望读者第一眼看到什么？
- 我的文字适合衬线还是无衬线？
- 暗色还是亮色？密集还是疏朗？

每一个选择，都是在定义「我是个什么样的写作者」。

## 技术上，门槛已经很低了

```ts
// 一个 Next.js API route，读取 markdown 并返回
export async function GET() {
  return NextResponse.json(getAllPosts());
}
```

Markdown 存文章，Git 做版本控制，Vercel 一键部署。整个链路不到一天就能跑起来。剩下的时间，留给真正重要的事——**写**。

## 所以

这个博客不会有很多读者，这没关系。它是我的一个房间，门牌号我自己定，墙刷什么颜色我说了算。欢迎进来坐坐。
