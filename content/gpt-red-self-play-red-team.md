GPT-Red 这篇论文，第一反应很直接：它到底在讲什么？

OpenAI 发布了一个专门做自动红队的模型，目标是大规模发现新颖的提示注入攻击，再用这些攻击去加固生产模型。它已经参与训练了 GPT-5.6，让后者成为他们迄今对提示注入最硬的版本。论文地址在文末。

## 它是什么，self-play 又能干什么

接着会问：这到底是一个模型吗？基于什么训练的？强化学习方式是不是就是 self-play？self-play 又能干什么？

答案是肯定的。GPT-Red 是一个专门的**攻击侧模型**，权重从 GPT-5.5 初始化，再用大规模强化学习练成红队专家。训练方式就是 self-play：攻击者和一群同时训练的防守模型互相打。

- 攻击成功 → 给奖励
- 防守挡住并完成原任务 → 也给奖励

两边一起更新。防守变强，攻击者就被迫想新招；攻击者变强，就给防守提供更难的数据。

self-play 的核心价值在于**自动生成无限自适应对抗数据**，不用靠人类红队或固定数据集。固定集很快会过拟合。它还会形成课程：简单攻击被修掉后，逼出更复杂策略。多防守模型训练能防止模式塌缩。最终形成飞轮——模型越硬，红队学习信号越好，红队更强，下一版模型更硬。

## 常见误解：攻击和防守是不是同一个模型

再往下想，会自然产生一个误解：既然是基于 5.5 基模做特殊强化学习，这个安全模型是不是既能攻击又能防御？defender 和 red 会不会是同一个模型的不同能力分支？

**不是。** GPT-Red 是专门的攻击者，从 GPT-5.5 初始化后用 self-play 强化学习练成红队专家。防守模型是另外一群（多是过去的 GPT-5 系列变体），同时一起训练。两边不是同一个模型的两个分支，而是独立参数在对抗更新。

攻击者专门学怎么注入成功，防守专门学怎么挡住并完成原任务。成功的攻击数据再拿去加固生产模型，比如 GPT-5.6。所以 GPT-Red 本身主要是攻击侧，防御能力提升发生在防守模型和生产模型上。

## 底层循环长什么样

理解了表层机制后，会想看底层技术实现。论文公开的实现可以概括成一个循环：

1. 每一步先随机采样一个真实任务场景和一个防守模型
2. 规定攻击只能插入特定位置（某个工具返回结果，或某个非特权文件的一小段）
3. 攻击者在带工具的环境里运行：有终端可以写代码、改文件，还有一个 `defender_model` 工具，可以把攻击内容塞进防守模型的对话里，观察完整轨迹、token 概率和评判反馈，然后反复修改再试
4. 中间测试的轨迹全部丢弃，只保留最终提交的攻击
5. 系统用程序和模型双重检查合法性，违规直接零分
6. 合法攻击插入后，防守模型从插入点继续跑完原任务
7. 双方根据结果分别得分：攻击者看目标是否达成，防守者看是否挡住攻击并完成原任务
8. 用强化学习同时更新两边

威胁模型很硬：攻击者只能动允许的位置，不能乱改系统提示或特权文件。多防守模型同时训练是为了防止攻击方式塌缩到几种固定招式，迫使攻击者学会针对不同模型的弱点出招。训练时还会混入普通能力任务，避免把正常能力练废。

## 用大白话再说一遍

这些描述一开始会显得专业术语过多。简化后其实很清楚：

先拿 GPT-5.5 当起点，练出一个专门负责攻击的模型。同时再练一群防守模型。训练过程像两个人一直对打。系统随机挑一个真实场景，规定攻击者只能动一个地方。攻击者可以反复试，写攻击内容、塞进去看防守反应、改了再试。试完提交最终攻击。系统检查是否合法。合法就让防守模型把任务跑完，然后分别打分并更新。

对应一下术语：

- **强化学习** = 根据结果好坏调整行为
- **self-play** = 攻击方和防守方同时训练、互相变强
- **agentic harness** = 给攻击模型一套工具，让它能自己写文件、反复测试，像人一样边试边改
- **威胁模型** = 规定攻击者现实中能碰什么、不能碰什么，防止作弊得分

攻击者每一步随机抽一个防守模型（从一群不同的防守模型里采样），打完就更新，然后下一轮再抽下一个。不是固定顺序打完一个再换，而是每轮独立采样。

OpenAI 只公开了高层方法和训练循环，具体用的强化学习算法变体、超参、防守模型群体怎么维护、batch 怎么组，这些都没公开。是的，攻击模型跑在 agent 环境里（有工具、能反复试），和防守模型一起通过强化学习共进化。

高层方法可以再浓缩一次：

> 用强化学习让一个攻击模型和一群防守模型同时对打、一起变强。攻击模型在带工具的 agent 环境里反复试攻击。防守模型一边挡攻击、一边完成原任务。两边根据结果同时更新参数。攻击变强，防守就被迫变强；防守变强，攻击就被迫想新招。最后用攻击模型生成的攻击数据，去加固正式生产模型。

核心就这套共进化循环。

## 值得单独拎出来的点

论文里还有一些值得单独拎出来的点。

它发现了新攻击手法，最典型的是**假思维链**：攻击内容故意模仿防守模型自己的推理过程，让防守模型以为那段话是自己之前想过的，直接照着执行。训练初期只会用简单的「忽略之前指令」，后期才会出现这种复杂招式。

真实系统也能打穿。它成功攻击了办公室里的 AI 售货机（改价格、下单、取消订单），以及 Codex CLI 这类真实 agent。比人类红队更强：在 2025 年间接提示注入挑战赛上找到的成功攻击比人类红队和普通 GPT-5.5 都多，而且给它更多测试时间成功率还会继续涨。

还支持多模态：攻击不只是文字，还能生成带恶意指令的图片塞进工具返回结果。训练有自然课程，简单攻击先出现，被防守模型学会挡住后成功率会掉，然后逼出更复杂攻击。

最终目标是飞轮：模型越硬，给红队的学习信号越好，红队更强，下一版模型更硬。他们已经用前几代红队模型从 GPT-5.2 开始持续加固了。论文也诚实地说，鲁棒性远没解决。

## 实验数字（趋势向）

训练用的算力和正式 GPT-5 系列的强化学习后训练差不多，是目前公开最大的安全向强化学习 run。从 GPT-5.5 初始化，混入普通能力任务数据。

在 2025 间接提示注入挑战赛上，GPT-Red 的成功率明显高于人类红队和普通 GPT-5.5。对早期 GPT-5 模型的攻击成功率更高。在十个内部数据外泄任务上，简单任务和 GPT-5.5 差不多，难任务上 GPT-Red 明显继续进步，GPT-5.5 会卡住。真实系统测试成功打穿售货机和 Codex CLI。

用它生成的攻击去加固后：

- GPT-5.6 在最难的直接提示注入基准上失败次数比四个月前的最好生产模型少六倍
- 假思维链攻击从早期模型的 95% 以上成功率降到 10% 以下
- 对 GPT-Red 自己生成的直接攻击，失败率只有 0.05%
- 多个间接注入基准达到 97% 以上

留出未训练过的场景和强攻击时，防守成功率仍能爬到 50% 到 89%。训练过程有明显课程现象，攻击有多样性，多防守模型训练比单防守模型更能防止攻击方式塌缩。

论文里的数字大多是趋势和相对提升，完整表格和精确超参没全部公开。

## 比赛里能不能借鉴

最后会落到实际用途上。如果在参加类似的红队 agent 比赛，模型权重不能更新，只靠 agent 层面优化攻击，这套思路还能不能用？

可以，但效果会弱一截。GPT-Red 的核心是**改权重的共进化**。模型不变的话，失去了真正的参数更新，只能靠 agent 层面的策略进化。能做的方向包括：

- 把每次成功和失败的攻击完整存下来
- 失败后强制反思为什么被挡、下次改哪几处
- 成功的模板沉淀成可复用策略库
- 用树搜索或简单进化生成多个变体再筛选
- 让 agent 写代码去组合变形已有成功攻击
- 允许在同一防守模型上连续试多次，带着历史上下文优化

这些本质上是推理时 scaling，论文里已经证明 agentic harness 本身就有效。上限很明显：没有权重更新，模型不会真正学会新攻击模式，只是在外部积累经验。遇到分布外的新防守模型时迁移会差很多，长期也容易陷入局部最优。

比赛如果允许外部记忆、多轮交互和代码执行，这套思路值得做。如果严格限制成单次生成、无状态，那就基本没戏。先做最简单的版本：成功攻击入库，失败强制反思，下次生成时强制参考历史。这已经比纯零样本强不少。

## 所以

整篇论文最有价值的地方，在于把「红队找漏洞 → 加固模型」做成了**在线共进化的闭环**。攻击和防守实时对打，数据自动变难，不再依赖人工持续写样本。这是目前把安全训练规模化的一条清晰路径。

从最初的「这是什么」，到机制、实现、结果，再到自己比赛能不能借鉴，一步步把论文读透，也就把这条路径看清楚了。
